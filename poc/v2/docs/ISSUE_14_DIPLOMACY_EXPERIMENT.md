## 本輪實作

依 Issue #14 交付優先順序，先完成真實遊戲核心中的 **接觸 → 和解 → 互助同盟 → 實際運輸 → 地圖辨識**。PoliticalUnion／共同對外決策尚未實作，不將盟約冒稱政治聯合，也不結案 #14。

- `politics.js` 從在世居民的 `religionId`、Devotion ≥40 核心人數與比率推導主要信仰；最低 3 名核心、40% 比重為可調實驗值。領袖信仰另計，不強制改宗。
- 每日只依既有 `contactLog` 的真實跨聚落接觸推進一次信任；共同核心信仰、領袖認同、公共庫存互補影響意願；領袖保留程度由 Seed 與人物 ID 決定。衝突、實際交戰回合與交戰中死亡提高舊怨。同教不能跳過接觸與舊怨條件，異教也可以合作。
- 和解同時阻止新內部礦區攻勢，將既有行軍或交戰改為無勝方撤退；兩村各自保留地方領袖、居民、宗教、瞭望塔與庫存。
- 和平至少維持 14 日、信任及互補利益符合條件才結盟。盟村有不足、來源村留足儲備、有合法路線與可派遣成年居民時，才派出真正居民運送 1.5 單位物資。排除領袖、民兵、聖職者和已有移動任務者。
- 出發即扣來源庫存；沿非河水格／渡口每日最多 4 格移動，抵達才入收貨庫存。運輸占用居民工作時間；送達後沿原路返村。途中死亡記錄貨物遺失，不重複入庫。沒有免費資源、兵力或防禦 Buff。
- 地圖顯示和平虛線、同盟實線及相同旗幟符號、居民運輸標記；聚落資訊顯示對象、關係、原因及累計運抵數量。關係資訊每頁一筆，可以切換，沒有無限增長的外交清單。外交轉換不自動暫停，也不更動原戰鬥暫停與速度控制。
- 重大轉換在關係資料中保存時間與當時原因，並寫歷史；不在每次評估時刷事件。既有存檔缺少外交資料時不自動補入；新世界可用政治 Profile 的 `diplomacy.enabled:false` 關閉。
- 自然長跑發現月底人口遷移可能留下非本地民兵的既有缺口，另補 `syncMembership()`；地方領袖離村時進入原有指揮真空，不將活人誤報死亡。

## 本機自然世界對照

Node **24.12.0**；三個固定 Seed，各跑外交開／關兩組、每組 **180 日**。使用實際 Agriculture、Religion、Mobility、Shrine、Divine、Opponent 與 Politics Profile。沒有人工改宗、增加居民、接觸或庫存，也沒有額外玩家施法；原本對手 AI 繼續運作。

|---|---:|---:|---:|---:|---:|---:|

| dry-stress | 8 → 1 | 10 | 9 | 10 | 15 | 23／40 |

村對為雙邊協議，**不代表有 6 個聯合國家**。總量合計不同物資，只用作守恆／運輸診斷，不代表價值或遊戲收益。全組共 1,080 模擬日，約數十秒，實際時間記錄於 JSON。每個模型日檢查 `W.validate()`，第180日存讀檔並額外比對一天重播；報表端點排除重播日。

這三個世界顯示可自然生成和平與實際互助，並保留部分未和解關係；樣本有限，不能宣稱平衡已定，也不能把減少的衝突全部歸因於共同信仰。外交會改變居民工作及後續世界路徑，A/B 只有初始世界一致，並非後續全部亂數呼叫一一對應。

## 受控驗證與回歸

`tests/diplomacy.test.cjs` 的接觸、信仰、存量與衝突是明示的受控案例，不能當作自然發生率。覆蓋：40 核心門檻、混教、領袖異教、無接觸、外交停用、深仇短期同教、行軍／交戰中和解、真實居民運輸及庫存守恆、在途死亡、地方領袖死亡、人口遷出、儲存與重播，以及地圖／inspector 瀏覽器 harness。

- `npm test`：213/213，約45秒。
- `node --test tests/polity-command.test.cjs tests/polity-intervention-ui.test.cjs tests/diplomacy.test.cjs tests/layout.test.cjs`：32/32，約6秒，涵蓋原 0.1×、接戰與首傷暫停、暫停中 Heal。
- `npm run smoke`：Original 與 Agriculture 通過。
- `npm run check:agriculture`：農業／氣候檢查通過。
- `npm run build:playable`、`npm run check:playable`：離線可玩檔已同步。

沒有增加或執行 CI 長跑；`test:polity` 只增加短外交單元案例，既有 CI 的 Node 24 與三分鐘 job 上限維持原值。地圖驗證使用既有瀏覽器 harness，尚未完成真人試玩的視覺驗收。

## 尚未解決與下一步

1. **PoliticalUnion、共同領袖及共同對外決策**尚未實作；聯盟保留地方90–180日指揮真空，但尚無中央政治層。
2. 和平／同盟目前無破約、退出或維護成本，接觸累積仍使同盟偏容易形成；改宗不強制解散，但也尚未模擬長期政治不穩。
3. 共同敵人尚未獨立建模；庫存差異只是最低成本的互補代理，尚未採用完整需求／收益評估。外交沒有額外「神明簽約」按鈕。
4. 運輸沒有護送、攔截、遺物回收或食物專用攜糧；死亡貨物明確計為損失，不當作世界總資源憑空守恆。現階段只支援短途盟村互助。
5. 自然樣本沒有為每種同教／混教／領袖死亡／改宗排列完整矩陣，這些邊界主要由受控案例覆蓋；「聯盟成立後改宗」只驗證不強制解盟，並未驗證危機下的長期穩定性。

建議先試玩和解與運輸是否看得懂，再決定同盟維護／退出成本，最後增加上層政治聯合。不要依這三個 Seed 直接固定同教和平率或宣布 #14 全部完成。
