# Issue #14 — World of God 地圖資訊圖層（2026-10-25）

## 背景與目標
第 303 日存檔中，外交線條隨著和平、同盟、聯合增加而大量交錯。這些都是不同村中心的直接連線（**不是實際交通路線或國界**），應只在需要時顯示。玩家首要關注居民、宗教神諭、神蹟、礦權與真正交戰。

## 介面與規格
- 位於世界地圖右上角的 **「圖層 · 一般」** 折疊選單，不佔用原本地圖寬度、速度列或固定 Inspector。選單可按 Escape 關閉。
- 三種快捷視圖：
  - **一般**（預設）：隱藏外交連線、聚落行政圓圈；保留礦點礦權、民兵戰場、宗教神諭、神蹟效果。正常地形、聚落名稱、家戶與居民常駐。
  - **外交**：顯示和平／同盟／政治聯合／破約連線與聚落行政圓；顯示礦點；預設只顯示右側目前選取聚落的連線（尚未選定聚落時顯示全部）。
  - **軍事**：突出礦權、部隊與戰場，隱藏干擾性的外交、行政、宗教標記；顯示與交戰相關的神蹟作用範圍。
- 六種獨立 Checkbox：**外交連線／聚落範圍／礦場礦權／民兵戰場／宗教神諭／神蹟效果**，並可勾選 **外交僅看選取聚落**。任意單項切換變成「圖層 · 自訂」。
- 隱藏宗教神諭時不再保留不可見的 Oracle、Temple、Priest 泡泡點擊熱區；隱藏民兵戰場後，地圖點擊不再選到隱藏戰場。
- **絕不隱藏**一般居民、房屋、聚落名稱、目前神蹟施法瞄準、需求定位和戰爭自動暫停通知；戰場焦點按鈕也持續可見，以免關閉軍事圖層造成錯過重大戰事。
- 圖層只是瀏覽器前端 presentation flag，不進 `state`、不進世界 JSON。切換不會消耗 DP、不會改變 tick、戰爭或政治決策，也不需要重新開始目前世界。
- 顯示偏好單獨儲存在 `localStorage('wog-v2-ui-map-layers-v1')`，可跨一般重新載入沿用；儲存失敗時仍保有當頁切換。這不是世界存檔格式的一部分。
- Web `?mineralRights=1/2/3` 和無 query 模式均使用同一圖層控制；完全不動 P0/P1/P1.5/P2 的資料或參數。

## 回歸測試／驗收
- `tests/map-layers.test.cjs` 在實際 browser adapter harness 上操作預設和 checkbox，驗證圖層開關真的控制不同 canvas 繪圖（不是只有更新按鈕），且所有操作完全不改世界 JSON、停頓、速度。
- 測試範圍：外交連線常態隱藏、可單獨開關；礦點、聚落行政圈、軍事標記、神蹟效果獨立切換；即使戰場圖層關閉，戰爭焦點按鈕仍在；居民可見；Escape 只收起圖層選單。
- Node.js **24**、GitHub 單 job **3 分鐘**上限。CI 只執行必要 UI／P2 契約與相關回歸、smoke、離線 Playable 一致性，不加長跑。
- 測試會在獨立功能分支 `codex/issue-14-map-layer-toggles` 執行。依 Issue #14 原則不動、不合併 `main`。

## 使用方式
地圖右上角點 **圖層** → 選 **一般／外交／軍事**；需要比較特殊資訊時勾選單一圖層。需要只看某村外交關係時，從「宗教」聚落 Inspector 選村，並確認「外交僅看選取聚落」已勾選。
