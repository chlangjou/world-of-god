## 實際程式路徑

1. `politics.js`：真人地方領袖僅在已經有在世真人守衛、對方確實缺石並有可通行路線時，評估更遠安全礦／協商／冒險進入。安全方案依真實可行路徑與公共石材需求，協商必須有期限內的**實際跨村居民接觸**。協商先等待 7 日；所有核准都記錄在人類領袖、互信、舊怨及現有礦存證據上。核准只是最多 3 石、20 日的通行額度；不是礦或庫存的直接轉移。
2. `mobility.js`：選址避讓只算計畫，`mobilityTrip` 真的走到替代石礦並從單一礦存取出，再真實回家 `distribute()` 後，才計入 `quarryAlternativeTripsDelivered`／`quarryAlternativeUnitsDelivered`。使用許可的採集當場消耗額度與實際礦存；通行逾期或額度耗盡，再由在世守衛限制。
3. 實際到場抗議才有 `challenge-resisted` 與 `quarryActualChallenges`；**政治意向不會無中生有地觸發戰鬥**。受控測試使既有真人沿合法地形走到守衛面前，礦存不會減少，也不啟動 P2 戰爭。
4. `app.js` 礦權 inspector 可直接看各村安全替代礦坐標、協商／許可、礦權守衛及額度；新模式仍符合單頁操作。

```bash

node tools/quarry-p1-5-experiment.cjs --days=180
```

- 快速契約明確區分**自然世界**與**受控**。內容涵蓋：舊旗標完全不受影響、既有正常居民到貨、從真實接觸來的通行許可、限制額度、拒絕虛構接觸、真人守衛死亡後恢復自由採礦、抗議的實際合法步行與守衛阻止、存讀檔及額外一日決定性重播。
- 三 Seed ×（P1 原版 / P1.5）× 180 日：每日 `W.validate`，在 30 / 60 / 120 / 180 日抽樣，終點 `restore`、額外 24 小時確定性重播均通過；所有自然案例無人工加人／造礦／控制領袖／改 Devotion／God 神蹟。
- 各同 Seed 配對的原生人口、地圖、家戶、初始 RNG 指紋相同；初始相同不代表過程 RNG 與個人決策也會始終成對，因此**不可把所有公共石材差值單純解釋成外交政策造成**。

## 收斂與下一輪界線

**可確認的 P1.5 最小完整正向證據：**「真人領袖判斷較安全天然礦 → 在世居民真實步行、從統一儲量採石 → 返村才入庫」；以及「既有實體接觸 → 人類協商 → 有額度與期限的許可 → 真實許可開採」。沒有額外賦予 God 指揮軍隊能力。

**尚缺：** P2 真實抗命後的小型摩擦／集結、談判破裂後的自治軍事決策、有限期礦權轉移、撤退及有明確結束條件的領土戰；另外協商前應更精確評估**真人採礦家戶的可達性**，降低「核准卻無人使用」的紙上許可。

下一 Session 建議把 **P2 最小礦權爭議結束閉環** 另開一個可回退的分支：前提是既有真人守衛、真正違抗／警告、多方領袖自主判斷；結果應是協商、撤退、時限礦權或有限軍事對峙，**不可又回到無限僵持、低庫存自動戰爭或只搶 1.5 石**。先受控、再三 Seed 有界自然驗收；不順手擴到帝國體系、新兵種或 Stone Genesis。
