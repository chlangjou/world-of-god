## 本輪最小實作
1. **許可先驗證可到貨性**：有在世、非民兵／守衛且可從真實家戶沿合法路線到礦場的 gatherer 才核准。許可提高正常採礦規劃吸引力，不額外給人、瞬間送石或新增 God 命令；以實際出礦與人員返回家戶入庫兩套 counter 追蹤收益。
2. **兩次實體到場**：第一次遭真人守衛阻攔產生 `guard-warning`；同村在時窗內再次由真人步行到達並抗命，才有 `challenge-resisted`。缺石或領袖單方面想打，都不直接變戰爭。
3. **自主升級**：需有真人雙方領袖、真正守衛、現役民兵、可行道路，未處於和平/結盟、暫停協商或其他停戰期；以 `escalationChance` 做人類自主決定。也可以選擇撤回，不硬寫每次抗命都要打。
4. **有限有結局**：原有民兵沿真實路線行軍，沿用現有 3 回合健康消耗、Healing、玩家交戰暫停；中途達成外交和平或超過 `maxDisputeDays` 就撤軍。最終可能守住、停戰或因訪客真人勝利而轉移礦權。
5. **轉讓不等於立即排他**：原守衛沿家戶路徑撤回，新方只是接下礦權主張，仍要真人行軍派守衛到礦點才能排他；不再把舊版一次性 1.5 石材戰利品當作領土戰成果。保存讀檔重播與礦存守恆照舊。

優先分析 **為何第一次真人警告之後，沒有相同外村再次到礦或領袖維持挑戰決策**，拆分居民採集出發機率／通行權供給／避讓安全路徑／民兵可用性／外交抑制等事實。不要靠提高 `escalationChance` 或憑空造犯規兵團製造自然戰爭；需要先讓世界合理產生人類衝突動機與第二次實體接觸。

## P2 補強：有限期礦權（避免永久占領）

- 新增可調 `mineralRights.transferDays=60`，只有**真人民兵實際勝利**才得到有限期的礦權主張；奪權後仍須真人走到礦點實際派守衛，否則依然共享可達礦。
- 暫時占有到期後，先前權利人的主張恢復為未駐守 `declared`；佔有人必須撤回真實守衛，雙方舊通行額度關閉，重新記錄短期停戰以防反覆瞬間翻轉。若到期時尚有真實交戰，先依 `maxDisputeDays` 完成有限結算再到期。
- 新增受控決勝契約：既有真人民兵確實行軍、調整測試交戰強度令訪客可勝、7 日有限礦權到期回復，檢查真人撤兵與單一礦存不會產生無來源戰利品。受控強度調整**不是自然勝率證據**。
- 此修正只會在自然界實際交戰、勝方拿到暫管權後才生效；已完成的三 Seed、180 日世界均為零礦戰，因此長跑的自然負結果不變；新提交需重新通過 CI。
