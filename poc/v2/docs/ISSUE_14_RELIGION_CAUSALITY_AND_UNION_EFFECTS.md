## 結論與證據範圍

1. **God → 真實受益／歸因 → 個人信仰變化存在。** 有限策略取得454筆新的玩家神歸因紀錄，其中452筆帶有正／負 Devotion 變化。雨回應祈求與工作效率的證據均來自核心，不是依施放次數推定。
2. **舊的共同核心宗教外交通道確實沒有發生。** 三個 Seed 的自然、合法策略與 Oracle-only 組，該加成的實際有接觸村對日均為0；領袖同教的另一條加成通道則有發生。玩家策略不是完全無效，但不能將兩種通道混稱「全村同教促成合作」。
3. **將20+宗教歸屬與40+核心凝聚分開的最小候選可實際改變信任與部分合作。** 選項預設關閉；信任係數、接觸、舊怨、運輸、軍事、核心40與改宗規則不變。受控同狀態契約隔離了宗教判定的影響；自然 A/B 仍有中途經濟／RNG路徑分歧。
4. **完整的自然世界「某次神力 → 某次和平」尚不能唯一歸因。** 神力也改變食物、工作、人物和接觸；普通傳教採納沒有逐人標記完整來源。現有證據可確認前半鏈與宗教→信任的規則作用，不能把所有和平增量或戰爭次數變化都算成純宗教因果。
5. **聯合已有真正的共同條約與中央真空效果。** 受控同源比較中，同盟會出兵，聯合會依成員協議／中央空缺停止該行動；政策一致且有領袖時，聯合也確實授權現有民兵行軍。自然組新增對外授權仍為0，沒有證明軍事效率或真人參與感提升。

## A．先不改數值的合法 God 策略

先跑既有神蹟歸因／Oracle配對／外交／聯合契約37項，再跑有限自然分支。三個 Seed 固定為 `valley-spring-01`、`dry-stress`、`opponent-competition-replay`。每個 Seed 的完整初始世界、所有 Profile 與 standard 對手 AI 一致，核對起點 SHA256。所有分支皆從正常存讀檔初始化；該初始化會補齊既有 granary placeholder，沒有新增物資或人物。

本輪補載正常 UI 使用的 `oracle-specialization-v0.1.json`，以驗證真實持續神諭和配對規則。此前外交報告未載入此 Profile，故不能把先前16批運輸直接當成本輪的同一基準；本輪配對之間的設定完全相同。

- **無干預自然組**：180日，玩家不施法；既有對手 AI 繼續。
- **有限 Oracle＋Miracle**：180日。第14、104個日槽各嘗試一次 `religion.spread`，只選實際在世 Saint，使用真實 quota。每21日只選一個目標、嘗試一次 Miracle：讀取祭司已彙整的最新祈求與真實需求中心，healing→Heal、food-water→Rain、food-shortage→Harvest；沒有相應祈求時，在可見 Saint／camp 施放 Efficiency。不使用未來資訊，不搜索最佳目標，不失敗重選，不強制冷卻內連發，不增加DP、聖徒或信徒。
- **Oracle-only 消融組**：120日，完全相同 Oracle 日程，沒有 Miracle。只與其他組的同一120日端點比較。

日槽操作發生在當日三個8小時tick之前，因此第21個日槽施法時已經過20日；資料內策略 `day` 是日槽編號，核心事件 `hour/24` 是實際經過日數。每個兩通道組實際成功1次 Oracle與8次 Miracle；Oracle-only每組成功1次 Oracle。104日槽的重複同類 Oracle被核心合法拒絕，沒有額外扣額度。

### 可追查的個人證據與缺口

例：`valley-spring-01` 的有限策略在第21日槽依已收集的缺水祈求施雨。世界第32日，`p2` 因核心判定「降雨改善農田與實際食物供應，回應當地祈求」，Devotion **33→45**，歸因 `g1`，實際跨越核心40門檻；同一人物、家戶與村落均保留。`p1` 同時70→82。後續 Efficiency 的歸因要等實際生產工作發生，施放本身的 `actual:0` 不能當成成果。

另一方面，普通採納常只有 `religionId`／Devotion變化，沒有新的個人歸因紀錄；runner 明確標為「change alone does not establish player causation」。`events` 中近期個人證據連結也是時間關聯，不宣稱該人造成整個政治決定。新候選在第23日已有部分和解，早於第32日的上述雨成果，因此不能把第23日的和解說成由那次雨的信仰獎勵造成。

## 最小、預設關閉的宗教判定 A/B

舊 `coreFaith()` 判定的是40+核心是否至少3人且占全村40%，不單是村莊宗教歸屬。觀測到許多村對有共同20+相對多數，舊共同核心加成仍為0，足以確認語意與門檻通道被混用；但這不能證明玩家策略其他效果全部由此造成。

新增 **`politicsProfile.diplomacy.identity20Enabled:true`**：

- 唯一20+信眾相對多數、至少原 `minCore` 數值3人、占人口至少原 `coreShare` 數值40%，才認定共同宗教身分；平手不強判。
- 40+核心人數與占比保留為獨立凝聚／信心資料，保存於 `faithAssessment` 及轉換事件；**40仍然是核心門檻**。
- 只切換共同宗教的輸入判定，既有共同宗教1.4、領袖同教0.2、接觸、舊怨與所有決定條件不變。核心凝聚度此輪只顯示，不另加一個新Buff。
- 預設 Profile、原有存檔與一般可玩世界不自動啟用。候選覆寫檔為 `config/religious-diplomacy-identity-v0.1.json`，測試時把其中開關合入政治 Profile 的 diplomacy。可沿既有minCore/coreShare調整實驗門檻，本輪沒有改其數字。

## B．同盟與聯合的真實世界受控比較

使用同樣三個Seed的自然軌跡，回到第一個聯合成立的前一日，完整世界雜湊相同後，僅在一般同盟組關閉上層聯合。這是研究者的反事實比較；不向有限God策略提供未來資訊。成立後各觀察28日，真實人物、地方領袖、庫存、民兵與路線保留。其他可能形成的上層聯合也受該旗標影響，並非只替換一個UI標籤。

沿用已驗證的外部石材預留帳與14日政策壓力，逐筆守恆並在原村釋回；沒有造兵、加材料、改信仰或免費戰力。每類每Seed兩組，合計18個受控分支。

| 受控條件 | 同盟組目標出兵（3 Seed合計） | 聯合組目標出兵 | 聯合實際新增授權 |
|---|---:|---:|---:|
| 一位成員維持對外村和平，另一位競爭礦區 | 3 | 0 | 0 |
| 雙方同意競爭礦區，但同一真實領袖死亡 | 3 | 0 | 0 |
| 雙方同意競爭礦區，共同領袖仍在世 | 3 | 3 | 3 |

中央死亡條件在兩組使用同一人、同一 `W.die()` 事件，讓其本村都承擔原地方真空；選擇仍存活的另一村作為行動者。聯合組另承擔共同指揮空缺，因而阻止其新攻勢；沒有把另一村的地方領袖或民兵刪掉。

真實行軍例：valley的同盟組產生14個行軍、6個交戰、14個撤退民兵活動人日，取得1.5石材；相同成員條約下，聯合組為112個守備人日、0行軍／交戰，0礦區所得。兩者守備與出征都占用工作，不能把不出兵直接當成免費生產力提升。報告另存每個單位座標、實際部隊、爭端／撤退原因、到貨與原村帳；座標位移只是記錄位移，不冒稱完整行軍成本。

共同授權組也不是必定獲勝：valley完成3輪並取得石材；dry-stress與opponent樣本分別在2輪／0輪後因後續成員條約撤退，無勝方。這證明共同政策能改變實際行為與戰果，不代表有數值戰力加成。

單一對外行動的限制另由既有真實礦區契約測試驗證；本輪小型三方比較不足以量化多戰線效率。自然組全部0授權仍是負結果，受控出兵數不能混入自然率。

## 是否增加新聯合作戰／補給行為

**本輪不再增加軍事機制。** 現有共同條約與中央真空已能造成可見不同的行軍／停止行動；自然組缺的是其出現條件與可追蹤的玩家因果，繼續加兵種或純Buff無法補上這個缺口。

若下一輪做「固定礦區的真實跨村補給」，可重用現有居民與路線，但仍至少跨越三個責任邊界：外出部隊的糧食來源／消耗、運輸目的地與到貨帳、地圖及儲存驗證。現有居民已從家戶吃飯，若直接另扣軍糧會雙重消耗。最低驗證應涵蓋守恆、無人可運、到貨前不計、撤退、死亡／損失與重播至少六類契約；目前自然樣本0戰事不足以估計收益，因此未先實作該擴充。
