# Issue #14：利益衝突、退出與破約

後續新增[預設門檻資源／政策壓力情境](ISSUE_14_PRESSURE_SCENARIOS.md)：從自然聯合分支實驗，未調低退出或破約門檻；下文保留無干預對照結果。

2026-10-24，接續 `d20c2d3` 的[兩村政治聯合](ISSUE_14_POLITICAL_UNION_EXPERIMENT.md)。沿用 `codex/issue-14-cooperation`，全部模擬在本機 Node24 執行。既有 CI workflow 和測試入口沒有修改。

## 已加入的因果鏈

聯合成員每天評估真實公共存量、已發生的互助運輸及共同對外政策。以下情況累積地方利益壓力：

1. 本村石材不足，對方也有需求，雙方確實可通往尚有石材的礦區，且有可用地方民兵；但盟村與外村的條約阻止本村行動。已在行軍／交戰、受既有戰爭冷卻限制，或對方聯合另有阻擋條約時，不把它算成可行機會。
2. 本村公共食物／木石儲備低，盟村有超過本地安全儲備的餘裕，但近7日沒有相應到貨，也沒有相應貨物在途。這代表對公共互助能力的不滿，不直接判定對方惡意拒援。
3. 本村近30日確實淨輸出木石給盟村，現在本村儲備低於盟村，形成持續的分攤爭議。

每項評估保存實際存量、公共糧食可支撐日數、礦區位置或受阻對象與原因。公共糧食指標只衡量政治公共儲備，**不是居民是否飢餓的判定**；家戶食物與原糧食可及邏輯保持不變。

可行礦區的條約分歧每日加2壓力，其他兩項各加1；沒有現存利益衝突時每日減2，範圍0–200。宗教差異、改宗、時間流逝或中央領袖死亡本身不加壓力。

## 通知、協商與分裂

預設聯合成立至少21日，地方利益壓力達24、且有在世地方領袖，才提出退出通知。通知有7日協商期；實際支援、存量改善或政策障礙消失後，壓力會下降，降至退出門檻一半以下即撤回通知。即使期限已過，當下沒有現存利益衝突，也不執行分裂。

期限到且現任地方領袖仍能確認時，有兩種結果：

- **和平退出**：兩村恢復獨立政治決策，保留雙邊和平，停止聯合互助義務與共同指揮。
- **單方破約**：利益壓力達36、仍有實際可行的礦區政策爭議，且當地領袖的既有 Seed／人物野心值至少0.7時，可能選擇否認原盟約。雙邊關係改為競爭，信任下降並增加12舊怨。野心數值是原型偏好的簡化，尚非完整政治效用模型。

兩者均保存退出者、現任領袖、當時原因／證據與實際時間。聯合保留為可儲存的歷史紀錄，但不再提供成員身分、共用旗幟、選舉、中央空窗或對外授權。此後人物死亡也不會重新啟動已解散聯合的繼承流程。

## 部隊、物資與冷卻

- 分裂時撤回所有原聯合正在進行的對外行動，雙方部隊沿原有路徑返村，沒有新增勝者或資源戰果。
- 已送達物資留在收貨村；未抵達的兩村互助貨物立即改沿「已行走的路徑前綴」返程。抵達來源村才退款一次。已經送達後返村的居民照常返程，沒有追回收貨庫存或瞬移退款。
- 地方領袖、人物、宗教、各村庫存、實體工事與民兵繼續存在；沒有強制資產重分配。
- 分裂後至少14日禁止相互發起礦區攻勢；新聯合亦不能繞過任何成員的該禁戰期限。和平退出本身仍保留和平，14日期滿不等於會自動開戰。
- 30日內不重新升級協議，90日內不得重新組成同一村對的聯合。期限後仍須重新達成信任、持續同盟、接觸及**分裂後新送達的物資**；舊運輸累計不能直接換回聯合。

所有門檻位於政治 Profile 的 `diplomacy.union.fracture`，可關閉。舊聯合存檔若沒有該設定，讀取時不自動啟用分裂；前兩輪 runner 的預設仍停用分裂，保留歷史對照意義。

## 地圖與操作體驗

退出協商期間，地圖顯示「退出協商」，聚落資訊顯示剩餘日數與當時原因。分裂後取消共同政治色與編號，改顯示「退出後和平」或「破約後競爭」，inspector 保留退出／破約原因與禁戰倒數。外交資訊沿用每頁一筆，事件只在通知、撤回與分裂時寫入歷史。

沒有新增玩家簽約／退出按鈕，也沒有增加外交自動暫停；既有0.1×、接戰與首傷暫停維持原規則。外交通知的傳遞目前仍抽象為聯合內協商，尚未增加獨立使者。

## 保留限制

分裂仍限兩村聯合的完整解散，沒有多村局部退出、稅賦、財產分割、賠償、扣押貨物、外交聲譽擴散或叛亂兵力。互助不足使用公共儲備作利益代理，尚未結合所有家戶私有資產與細緻政治派系；破約偏好仍簡化。自然樣本尚無分裂，後續應增加明示的資源壓力／政策分歧情境與真人試玩觀察，再調整遊戲性。地圖目前由既有 browser harness 檢查，未做真人視覺驗收。

沒有修改 workflow 或既有 CI script，也沒有把本輪測試、模擬加入 GitHub CI。新增 `test:fracture`／`evaluate:fracture` 僅為本機手動入口。Issue #14 保持開啟。
