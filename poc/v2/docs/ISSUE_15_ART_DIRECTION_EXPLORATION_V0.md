## 原創樣板：在同一場景控制變因

三份純向量畫面，`assets/styles/style-A.svgz`／`style-B.svgz`／`style-C.svgz`，各 960×620。都是本輪直接繪製的、可解壓為 SVG 的美術**樣板**，不是 AI 概念圖代替遊戲 Sprite、不是既有 Pixel PNG 改色或拉伸，也不是已對齊的動畫 Sprite Sheet。以獨立 `<img>` 方式 HTTP 載入。素材沒有引入第三方授權圖片；著作與改作可留在本 repo。SVG 直接向量化只為比較畫風；正式角色仍須重新考慮遊戲尺吋、腳底錨點和動畫品質。

三者相同的 960×620 座標系、相同村落內容與順序：

| 物件 | 固定內容與展示 |
| --- | --- |
| 房屋 | 一間完成的住宅（屋頂、門窗、門前土路） |
| 農田 | 同一塊長方形耕地、數排作物 |
| 自然 | 一棵大樹、草地、土、岩石、部分河岸與河水 |
| 成人一 | 有圍裙的農作者，位於 `translate(544 461)`，面向農田工作 |
| 成人二 | 深色髮型、持籃的步行者，位於 `translate(364 474)` |
| 兒童 | 低矮身形、不同衣服與髮型，位於 `translate(468 526)` |

相同人物位置不代表樣板已可追蹤同一個遊戲 person ID。正式的 identity 維持以世界現有 ID 的**穩定非 RNG**呈現變體；本輪沒有擴增居民人格、情緒數值、強制事件或虛構行為。

### 定性比較（初步專業評估，非玩家結論）

| 項目 | A 柔和繪本 | B 乾淨 2D 卡通 | C 2.5D 玩具模型 |
| --- | --- | --- | --- |
| 視覺舒適 | 高；溫暖柔和 | 高；清楚、平衡 | 高；柔和立體但較活躍 |
| 成人／兒童辨識 | 中高，靠髮型服裝與姿態 | **高**，輪廓色塊易掃視 | 中高，近景效果好但群聚可能擁擠 |
| 背景視覺雜訊 | 低；大色塊、紙感 | **低**；最容易控制 | 中；光影與體積可能分散注意力 |
| 動畫／百人變體 | 中高工作量；繪製一致性需把關 | **相對低**；可做頭髮／衣服／配件組合和 2D rig | **相對高**；3D 源模型或多角度預渲染一致性 |
| 角色／場景統一 | 可達成，需畫師維持筆觸 | 最容易規範輪廓、色彩和陰影 | 可達成，需統一光照、材質與視角 |
| 本階段風險 | 放大時過淡，人物易融入背景 | 過度簡化會回到 icon | 量產成本與遮擋、素材角度可能過大 |

**優先推薦 B**，不是因為其樣板工程較完整，而是輪廓、成人兒童差異、角色造型與多數居民顯示成本的平衡最好。B 需維持 A 風格的暖色與柔和地表，避免過於平板；不進一步製作 B 正式大批素材直到使用者確認。C 可留作重要建築/神蹟的材質參考，不代表已決定混用畫風。

### 人物共感驗收條件

1. 4× 時能不靠文字區別成年人、兒童，以及兩位成年人的服裝、髮型與身形。
2. 8× 時角色臉部、衣物和動作是「居民」而不是放大的標示圖示。
3. 同一居民行走、工作、休息、祈禱仍維持同一外觀與腳底錨點；動畫不能靠每 tick 換位置假裝連續動作。
4. 真實世界房屋、田地、地形與人物輪廓統一，地圖 8× 不因放大而粗糙。
5. 數百名居民的變體與動畫必須有可預估的製作成本；這階段不擴張六職業 Sprite Sheet。
6. 身分識別與表情只來自既有年齡、活動、健康、ID、已有職責資料；不加入心理或劇本模擬。

## 技術與測試

- 多檔案 Web 是今後唯一必要啟動方式；原 `tools/serve.cjs` 沿用，只新增 SVGZ 的 `image/svg+xml` + `Content-Encoding: gzip` 及 PNG MIME。
- `src/sim.js`、`src/mobility.js`、政治／AI／宗教／Presence、8 小時 tick、Devotion40、Seed、存檔與重播皆未修改。已有原生遊戲入口及過去 Sprite 可回退。
- `World-of-God-Playable.html` 歷史單檔不刪除，但此分支 **不 build、不 update、不跑 parity**，未來改美術只需換獨立素材。
- `npm run test:art` 驗證三份原創 gzip SVG 原始 bytes、固定座標與差異、比較頁和分離資源，CI 再跑 P0／Camera／施法快速回歸、HTTP 靜態資源與真正 Chromium 比較頁截圖。
- GitHub Actions：Node 24；單 Job <=3 分鐘，步驟加 timeout；如失敗需讀 job log 對症修復。**CI green ≠ 玩家美術認可**。

## 決策停損點

此分支最後的交付是**可觀察、可選擇**的三款風格樣板與工程環境。下一輪只在玩家明確選擇畫風後，才製作最小可真正載入遊戲的成人 A、成人 B、兒童三人活動姿態原型，再用同一份自然存檔 4×／8× 評估。**不現在擴製 Priest、Saint、老人、民兵或整套地景。**
