# Issue #15 — Character Size Stability v0 (2026-10-26)

## 玩家觀察及根因
在放大顯示中，同為成年人卻有巨大／微小的角色，甚至同一角色會在不同行動時突然變大變小。已核對前版 `src/living-world.js` 使用 `count === 1 ? 1 : count <= 2 ? .55 : count <= 5 ? .37 : .28` 決定**整個人物的顯示倍率**。因此只要別人進出同一格，人物的尺寸就會瞬間跳變；與角色實際成長無關。先前兒童主要只有頭較小，身體的年齡比例並未一致調整。

## 修正契約
- 人物尺寸只由**Camera 連續縮放**與**個人年齡階段**計算，不得依群聚人數、位置排序、選取或居民暫時進出群組變動。
- 1× 保持現有戰略全圖正常成年人的標記比例；在 1×–4× Camera zoom 間平滑調整表示尺寸；4×–8× 維持相同相對世界格比例（放大倍率仍使絕對像素增大）。
- 成年人近景統一 `0.52×` 每格的原始人型比例。兒童使用基於年齡的平滑比例：`clamp(0.58 + 0.42×age/18, 0.58, 0.98)`，與相同鏡頭的成年人相比較小；長者略微縮小至 0.95，不推測其心情或新增成長系統。繪製眼睛／頭與身體統一跟著此比例，不再只縮小兒童的頭。
- 同格分開站位、1× 人數徽章、4× 5 人／8× 8 人可見上限、分頁清單與個別 hit testing 都保留。站位只屬 UI，不修改真實居民 `p.x/p.y`、行動軌跡、8 小時 tick、施法、宗教或人口。
- 繼承 `codex/issue-15-crowd-selection-v0` 預先通過的版本 `7212a64`；開獨立修正分支，**`main` 不改／不 merge**，持續維持舊第 303 日存檔與 Offline Playable 相容。

## 檢查
- 2／5／10 人、1×／4×／8×：單名成年人不因同格人數切換而縮放；9 歲兒童永遠小於成年人、接近成年者有平滑比例，並且單人／多人尺寸一致。
- 同格人數增減後，已顯示人物的實際點擊區仍對應正確人員；聚集列表、Heal 和 Priest 定位維持。
- Node.js 24，GitHub Actions 單 Job ≤3 分鐘。涵蓋舊 Camera、群聚選取、Miracle、地圖圖層、戰場自動暫停、Smoke 與離線 playable parity。CI 失敗必須讀 log 並修正。
- **仍須真人視覺驗收**：這次只修正角色無理由忽大忽小；群聚密度高時仍可能互相遮擋，需要玩家實際觀察再決定是否要調整群聚展示方式，不另造碰撞模型。
