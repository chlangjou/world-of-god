# Issue #15 — Living World Camera / Acting v0 (2026-10-25)

## 目標與真正的缺口
玩家實際試玩表示上一輪只改善 Miracle UI 操作，64×64 全圖上居民仍像不會活動的標記，沒有感受到 God 干預真人的後果。因此本輪保留既有模擬規則，改以**觀看真人生活與表演**作為重點，不再擴充外交或平衡矩陣。

## 獨立功能分支
`codex/issue-15-living-world-v0` 從已測試的 #15 首輪 HEAD `fac10452` 建立；`main` 未改、不自行 merge。保留 Issue #14 地圖圖層、真實第 303 日存檔相容性。舊世界資料欄位與規則完全不變。

## 新操作
- **全圖 1×**：保留 64×64 地圖與原圖層，原有 God 奇蹟／Oracle／祈願／戰場介入方式不變。
- **2×、4×、8×**：左上方 ＋／−，Canvas 上滾輪可作任意倍率縮放（1–8）並保持游標所在世界座標；「全圖」恢復 1×。拖曳地圖平移（正在瞄準 Miracle 時按住 Shift 才平移），Camera 在地圖範圍內約束。
- **追蹤居民**：先在「居民」面板挑選，按地圖上方「追蹤居民」自動進入至少 4× 並跟隨他的實際/視覺位置。地圖資訊列顯示同一個人物 ID 的工作與健康，供觀察 Miracle 前後真實變化。再按一次離開；任意滾輪縮放或手動拖曳可解除跟隨。
- **近景視覺**：使用既有真人資料（`activity`、`health`、`hunger`、`campInjury`）繪製角色眼睛／表情／手勢，辨識工作、休息、祈禱、受傷；只有真的成功 Heal 造成健康上升的居民，才短暫出現康復視覺提示。
- **tick 連續性**：`src/living-world.js` 保存純顯示用的 tick 前/後 Snapshot，優先使用既有 `mobilityTrace` 路徑沿線按長度插值；沒有 trace 的短途用視覺過渡，無 trace 的長距離搬家直接跳轉，不杜撰沿路接觸。0.1× 至 4× 插值，高速 16× 跳過中間演出。**8 小時 tick 不拆、不改真實 AI 決策**。
- **獨立畫格**：地圖在近景時最多約 30fps 畫動畫；Inspector 仍維持原約 7fps 節奏。地形只繪製可見格，避免整張地圖高倍重新繪製。停頓時動畫時鐘也凍結，緊急戰鬥自動暫停顯示實際世界位置。
- **手動施法判定**：所有 God 手動施法、Prayer、人物、Priest、戰場 hit testing，都先將畫面座標**逆轉換為世界座標**；Heal/Lightning 永遠讓原 `S.castMiracle` 判定，不以視覺位置生成物理後果。
- **技術邊界**：`src/sim.js`、`src/mobility.js`、`src/politics.js`、Profile、Devotion40、Presence、資源守恆、Seed、存讀檔均未修改。純 UI Camera 不保存到世界 JSON；載入／重新創世重設為 1×。

用「自然河谷」或匯入既有真實第 303 日存檔，先在 1× 看全局，再 4×–8× 選取一位真人，觀察出門、工作、祈禱或受傷；有真傷者才施放 Heal。確認玩家能口頭說出是誰、在做什麼、哪一個健康／行為真的變了，以及下一個想做什麼。不人工強制改宗／傷病／戰爭作為玩法證據。
