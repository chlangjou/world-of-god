# World of God · 宗教策略試玩版 v0.1

日期：2026-10-15｜功能分支：`feature/opponent-difficulty-profiles-v0.3`｜`main` 不動

## 立即玩（無需安裝）

1. 在 GitHub 功能分支下載 `poc/v2/World-of-God-Playable.html` 的 **Raw** 檔案。
2. 以 Edge／Chrome 開啟下載的 HTML；所有 CSS、JSON Profile、模擬與畫面程式都已嵌入，不依賴外部網站、`fetch` 或本機 HTTP 服務。
3. 預設是「30人宗教對決」。切換 Oracle →「育兒」→「傳下神諭」，再按開始及 16×。
4. 查看主畫面「淨改宗」與「居民」中的「異教信任」、改宗前 Devotion、歷史中的自主轉宗。對手已先發出「存糧」神諭。
5. 可切換「自然河谷」玩原本的拓荒與 AI，切換時需重創世界；先匯出 JSON 備份。

或者安裝 Node.js 18+，在多檔案來源下使用 `cd poc/v2 && npm start` 後開啟 `http://localhost:8000`。單檔對應 `npm run build:standalone` 輸出的 `dist/World-of-God-PoC-v2.html`；CI 會驗證這份離線產物與提交的 `World-of-God-Playable.html` 完全相同。

## 場景設計

| 模式 | 開局與 AI | 玩家要觀察什麼 |
|---|---|---|
| 30人宗教對決（預設） | 受控 Day10、兩邊各15名 Devotion 60、已建好住所、正常自發出現的 Saint／Priest；AI 固定持續存糧，Day360 前不重選策略及施法 | 在100天內能否從對手原15名信徒淨爭取3名；玩家可自由選 Miracle／Oracle，不人工派任居民 |
| 自然河谷 | Day0，既有真實地圖、原生中立村落、AI 正常以標準難度自主思考 | 世界能否自然建立跨聚落傳播與可歸因的神諭成果，觀察信仰競爭；不保證100天內出現改宗 |

對決使用與前次 `oracle-30-core-ratio-sweep` 相同的初始人口、家戶及地圖整理方式，只在開局設定15:15及建好住所；正式模擬開始後沒有指定信徒或瞬間讓他們改宗。AI 的存糧神諭是開局劇情已公布的固定政策，不是玩家控制 AI 後台作弊。

## 可調節實驗 Profile

`config/playable-evidence-v0.1.json` 已獨立放入功能分支，不更改 `config/oracle-specialization-v0.1.json` 的舊預設、舊存檔或原本 40 的核心信徒門檻。

- 對決：育兒剋存糧仍採原1.6:0.4防禦表；對手神諭已啟用；原 Devotion 每次成功動搖2.5個百分點、同一人最短7天再接觸。
- 真實可信證據累積吸引力：成功有理由的跨聚落神諭接觸、至少5次可追溯證據、21天內仍有近期接觸與活躍同來源傳教者，信任分數不低於原 Devotion，經有上限的自主機率改宗。單次下達神諭及普通傳教不能直接轉宗40+。
- 為便於對照，對決使用同人同時點抽樣 `counterPairedRandom=true`、每次可信成果加8信任；自然河谷為一般 RNG、每次加6信任。這些數值**還沒完成平衡驗證**。
- 新改宗居民先以20–39的信仰加入；需要後續真實生活、傳教與神蹟才能自然成為40+核心。首頁大數字 `信徒` 指 **40+**，底下的淨改宗追蹤宗教身分改變，不能混用。

## 已知限制（請特別觀察）

- Day100 後可能過快出現全村連鎖改宗：過往三種子對照在 Day100淨爭取3／5／3名，Day130就累積12／11／11名。這是尚未修復的**平衡風險**，不是遊戲勝利判定。
- 先前結果只在被設計的30人受控地圖上驗證了「育兒 vs 存糧」一個剋制方向；探索 vs 育兒與存糧 vs 探索仍缺自然成果及接觸條件。
- 對決也保留神蹟中心 Presence 攻擊限制，不能無條件直接傷害對手。自然河谷則仍可能缺乏可觀察的跨村接觸。
- Web PoC 的畫面屬實驗用固定視窗，主要為桌面 Edge／Chrome設計；未做全面效能或不同瀏覽器尺寸的人工 UI 驗收。
- 點擊「重新創世／切換場景」會失去未儲存進度，存讀檔延用原版功能。舊 JSON 存檔匯入後不會被自動轉成30人對決或偷偷升級新信任演算法。
