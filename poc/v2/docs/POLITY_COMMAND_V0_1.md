# Polity Command v0.1 — 可回退的政治／軍事 Vertical Slice

Status: **experimental**, Issue [#13](https://github.com/chlangjou/world-of-god/issues/13), 延伸 #9。這不是正式國家制度或政教關係規格。

## 暫定原則
- 神可以在既有 Local Presence 條件允許時施放 Lightning 殺領袖；不能直接當國王下軍事或建設命令。
- 人類政體指揮真正的人類居民，基礎生產和宗教不依附統治者；政體和宗教維持獨立。
- 領袖死亡的指揮真空是**人類組織成本**，不是神力削弱／攻擊性 Miracle 免疫。
- 失去領袖：立即撤回已發起的進攻，停止新攻勢，指揮型防禦加成變成 50%；物理工事、防守兵力、居民農業不直接折半。90–180 日之後從在世本地成人推舉新領袖，值由 Seed、人物與死亡時間可重現。
- 王國、多聚落政治實體、繼承制度差異、結盟/停戰、正式占領/叛亂屬後續開放問題。

## 試玩機制
- 啟動入口：\`config/polity-command-v0.1.json\` 的 \`enabled:true\`。新建立的瀏覽器世界會套用；改成 \`false\` 可完全關閉。原始 \`W.create()\` 與缺少此資料的舊存檔不啟用。
- 每個已存在且至少有一位可任職成年居民的聚落暫時是一個獨立 \`polity\`；**不憑空創造人口、宗教或資源**。
- 領導者從居民的實際健康與技能推舉，不必與多數居民同信仰；有限民兵來自其他實際成年居民，值勤期間不從事原工作。
- 地方領袖動用公共實際木、石庫存，居民用工作時段施工，完成瞭望塔。實體塔提供固定防禦；另有指揮加成，在領袖真空期間減半。
- 兩個附近聚落在石材短缺且都可通往同一個實際石礦時，可能自主發生衝突。民兵每日沿非河水格／已有渡口**步行**，雙方到位才依參戰人員、健康與區域防禦結算，敗方撤回。取得的小量石材由實際地圖石礦扣除，進入勝方原有公共庫存；歷史紀錄保留原因。
- 國王被神蹟擊殺時走 **原本的 \`die()\`**；既有攻擊性神蹟 Presence 不改，也沒有新的「讓 God 指揮士兵」API。
- 聚落 inspector 在宗教資訊下加上一行「政體／領袖或空窗／民兵／瞭望塔」。

## 界線與待驗證
1. 目前每個聚落各為一個獨立政體，還不是合併的國家/王國。
2. 僅有一種民兵及瞭望塔；防禦分數、非致命優先戰鬥為**小型遊戲原型**，沒有武器/訓練科技樹、占領、外交條約。
3. 除了既有家戶糧食消耗，還沒有遠征獨立的口糧運輸。短途礦區行軍只作為驗證用的局部衝突；下一輪應補入可負擔且實際扣除的遠征口糧/後勤。
4. 石礦戰勝是一次小量資源取得，不等於永久獨占整個礦區。
5. 守軍以單位座標步行，但還沒有個體陣型及攻城路徑；大型國戰需另設獨立模型。
6. 政治事件與信仰轉換不綁死；神蹟可能造成後續間接影響，但此版本不額外給信仰跳動。
7. 若 \`polity\` 已載入存檔，\`restore()\` 保留其狀態與事件時鐘；舊存檔不被自動套上政治系統。
